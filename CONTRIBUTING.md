# Contributing to Nida

Thanks for helping! Bug reports, feature ideas, new sounds and translations are all welcome.

## Reporting a bug

Open an [issue](https://github.com/joohann/Nida/issues/new/choose) and include your Home Assistant version, the Nida version, what you expected, what happened, and relevant logs (**Settings → System → Logs**). Please remove any personal data first.

## Suggesting a feature

Open an issue using the feature request template and describe the problem you want solved.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep changes focused; one topic per pull request.
3. Make sure the Hassfest and HACS Validate workflows pass.
4. Describe what changed and why, and update `CHANGELOG.md` for user-visible changes.

## Translations and documentation

The English `README.md` is leading. The Dutch, Indonesian and Arabic READMEs must follow it. UI strings live in `custom_components/nida/translations/`.

## Conduct

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
