## ✨ المميزات

- 🕐 **مواقيت الصلاة الكاملة** — الإمساك، الفجر، الشروق، الظهر، العصر، الغروب، المغرب، العشاء، ومنتصف الليل  
- 📅 **التقويم الهجري** — التاريخ واليوم والشهر والسنة والمناسبات الإسلامية  
- 🔊 **أذان تلقائي** — يتم تشغيله عبر أي مشغّل وسائط (media_player)  
- 🔔 **تنبيهات قبل الأذان** — حتى تنبيهين مع صوت و/أو رسالة منطوقة (TTS)  
- 🌙 **ميزات رمضان** — تشغيل الترحيم قبل الفجر ومنبّه السحور  
- 🌙 **وضع خفض الصوت الليلي** — تقليل الصوت تلقائيًا بعد ساعة محددة  
- 📱 **إشعارات فورية** — استقبال إشعار عند دخول وقت كل صلاة  
- ⏭️ **مستشعر الصلاة القادمة** — يعرض الصلاة التالية ووقتها  
- 🎵 **خدمات المعاينة** — اختبار الأذان والترحيم مباشرة من الواجهة  
- 📊 **بطاقة لوحة التحكم** — بطاقة أنيقة مع عدّ تنازلي مباشر  
- 🌍 **أكثر من 15 طريقة حساب** — منها رابطة العالم الإسلامي، ISNA، كراتشي وغيرها  
- 🗣️ **دعم متعدد اللغات**

## 📦 التثبيت عبر HACS

1. انتقل إلى **HACS → Integrations → ⋮ → Custom Repositories**
2. أضف الرابط: `https://github.com/joohann/Nida`
3. اختر الفئة: **Integration**
4. اضغط **Download**
5. أعد تشغيل Home Assistant

---

## ⚙️ الإعداد

اذهب إلى:

**Settings → Devices & Services → Add Integration → Nida**

يتكوّن الإعداد من 6 خطوات:

---
<div dir="rtl" align="right">

### الخطوة 1 — الموقع وطريقة الحساب

| الحقل | الوصف | مثال |
|---|---|---|
| المدينة | مدينتك | `Riyadh` |
| الدولة | دولتك | `Saudi Arabia` |
| طريقة الحساب | طريقة احتساب مواقيت الصلاة | `Muslim World League` |

---
</div><div dir="rtl" align="right">


### الخطوة 2 — تنبيهات قبل الأذان

يمكنك إعداد حتى تنبيهين قبل كل صلاة.

| الحقل | الوصف |
|---|---|
| تفعيل التنبيه | تشغيل / إيقاف |
| عدد الدقائق قبل الأذان | مثل `10` أو `5` |
| الصوت | نغمة اختيارية |
| اللغة | ar / en / nl / وغيرها |
| الرسالة | مثال: `بعد [minutes] دقيقة يحين وقت صلاة [prayer]` |

استخدم `[minutes]` و `[prayer]` كمتغيرات داخل الرسالة.

---
</div><div dir="rtl" align="right">

### الخطوة 3 — أذان الفجر

إعدادات منفصلة لأذان الفجر (غالبًا بتلاوة مختلفة).

| الحقل | الوصف |
|---|---|
| صوت أذان الفجر | اختر ملف MP3 |
| المشغّل | كيان media_player |
| مستوى الصوت | 0 – 100% |

---
</div><div dir="rtl" align="right">
### الخطوة 4 — الأذان اليومي

| الحقل | الوصف |
|---|---|
| صوت الأذان | اختر ملف MP3 |
| المشغّل | كيان media_player |
| مستوى الصوت | 0 – 100% |
| خفض الصوت الليلي | خيار لتقليل الصوت بعد ساعة معينة |
| بداية الوضع الليلي | الساعة التي يبدأ عندها خفض الصوت |

---
</div><div dir="rtl" align="right">
### الخطوة 5 — الإشعارات

| الحقل | الوصف |
|---|---|
| إشعار عند كل صلاة | إرسال إشعار عند دخول الوقت |
| إرسال إلى | اختر خدمة notify |
| العنوان | عنوان الإشعار |
| الرسالة | استخدم `{prayer}` داخل النص |

---
</div><div dir="rtl" align="right">
### الخطوة 6 — رمضان

| الحقل | الوصف |
|---|---|
| منبّه السحور | تشغيل صوت قبل الإمساك |
| عدد الدقائق قبل الإمساك | تحديد الوقت |
| صوت السحور | اختر ملف MP3 |
| مستوى الصوت | 0 – 100% |
| تفعيل الترحيم | تشغيل الترحيم قبل الفجر |
| صوت الترحيم | اختر ملف MP3 |
| المشغّل | كيان media_player |
| مستوى صوت الترحيم | 0 – 100% |

يتم تشغيل الترحيم تلقائيًا قبل الفجر بـ 6.5 دقيقة خلال شهر رمضان.

</div>

## 🔊 ملفات الصوت

ضع ملفات MP3 داخل مجلد `sounds/` في التكامل.  
يتم تصنيف الملفات تلقائيًا حسب الاسم.
